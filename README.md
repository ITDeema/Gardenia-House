

# 🌸 Gardenia House - Web Application

## 📌 Overview

**Gardenia House** is an interactive web platform designed for flower and plant enthusiasts. The platform provides a seamless experience, allowing users to browse services, request floral arrangements, and book gardening services, making nature accessible through a modern, user-friendly interface.



## 🛠 Project Functionalities

### Core Features:

* **Service Catalog:** A diverse showcase of floral and landscaping services with detailed pricing.
* **Customer Dashboard:** A personalized interface for users to track the status of their requests (Pending, Provided, or Declined).
* **Service Provider Dashboard:** A comprehensive administrative system allowing the provider to add new services, update pricing, and efficiently manage the staff list.
* **Staff Management:** Detailed staff profiles showcasing professional expertise, skills, and academic background.

### Interactive Features:

* **Flower Fact:** A dynamic feature that displays a new, fun fact about flowers with every visit to the site.
* **Find Your Flower Quiz:** An interactive personality test that helps users discover which flower matches their personality based on their preferences.
